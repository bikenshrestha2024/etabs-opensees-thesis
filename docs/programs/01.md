# 01 — Main launcher

Open [`01.py`](../../01.py) in Spyder and run it, or execute `python 01.py`
from the complete repository. It launches the established ETABS/OpenSees GUI;
no numerical engine was moved or replaced. The previous `01_WORKFLOW_START.py`
and `01_START_ETABS_TO_OPENSEES.py` names remain compatibility entry points.

Use the [numbered program index](00_PROGRAM_INDEX.md) in ascending order to
find individual modules. Launcher numbers are navigation IDs, not approval
to run analyses before their source/material/gravity gates are satisfied.

All distributed workbooks are under [`excel/`](../../excel/README.md).
Run `git lfs pull` after cloning to retrieve the full ETABS table workbook.
Original source EDB and workbook hashes must still match the chosen project.

The primary gravity case is 32 nodes; individual ETABS reaction equivalence
remains unresolved. See the [decision record](../review/EXCEL_AND_LAUNCHER_PUBLICATION_DECISIONS.md).
