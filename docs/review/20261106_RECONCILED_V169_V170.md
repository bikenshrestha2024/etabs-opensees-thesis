## Why the old pull requests should remain separate

They are historical drafts with outdated assumptions, not completed native-verified changes. The reusable functionality was rebased and implemented in the current codebase with tests; attempting to force-merge the original commits would risk reverting tested features.

## Verification and engineering limitations

`tests/verify_v170_modern_reconciliation.py` runs synthetic duration and cancellation tests. Existing modal case-status tests and all repository CI must pass. Native Windows ETABS v23 and OpenSeesPy are not available in GitHub Linux CI. In particular, cancellation of a native eigen solver may require testing whether ETABS/OpenSees child processes terminate on Windows. A truncated linear record is a diagnostic and can never be counted as an accepted full-record Soil C XY/YX history.
