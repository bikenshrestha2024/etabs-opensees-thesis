# Independent research batch execution

Batch preflight resolves convergence settings before computing the job fingerprint. A new exploratory job uses `1e-6` with 40 iterations per attempt. Set `convergence_tolerance` to `1e-7` and `final_relaxed_tolerance` to `null` for a strict job. Saved strict-first fallback configurations retain their original settings. Invalid settings fail before source hashing or solver launch. A default and an explicit equivalent setting produce the same job identity.
Accepts a JSON plan containing a `jobs` array of saved configuration JSON paths. Each worker uses a separate native process and fresh output directory. Default 1, maximum 4 workers; increase only after RAM measurement. Source and waveform hashes are recorded and checked before launch. Duplicate job fingerprints and output overlap with source are rejected. `STOP_REQUESTED` requests cancellation. A process exit with a summary does not prove full-history completion or engineering acceptance. Production THESIS_NLTHA configurations are rejected by this exploratory scheduler.
