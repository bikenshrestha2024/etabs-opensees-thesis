## 2026-11-27 — direct analytical-element API extraction

Unlike authored PointObj/AreaObj/FrameObj tables, the analyzed CSI model exposes PointElm, AreaElm and LineElm. In the existing case-scoped native quantity extraction, the new helper requires read-back kN-m-C units (6), reads the analytical point name list, global XYZ, six local restraint flags, raw transformation matrix, parent object, named constraints, analytical line/area point connectivity and parent object identity. No geometric point merging or inference of actual physical supports from restraint counts. Records with API failures retain null fields plus errors. The new `ETABS_NATIVE_ANALYTICAL_MESH.json` is SHA256-linked in the manifest and included in existing direct evidence packaging. If APIs or generated mesh are unavailable, capture explicit failure; raw tables are retained. No source changes, no fabricated mesh, no internal MPC equations inferred. Public documented signatures from CSI ETABS 2016 (the installed v23 COM ABI needs native execution): [PointElm interface](https://docs.csiamerica.com/help-files/etabs-api-2016/html/c84a7f73-e47d-5191-a0d2-145a485df396.htm), [GetConstraint](https://docs.csiamerica.com/help-files/etabs-api-2016/html/8f0229a4-569d-a6c9-6055-04a6eb9b077e.htm), [AreaElm.GetPoints](https://docs.csiamerica.com/help-files/etabs-api-2016/html/259fd727-f33d-7889-6ee6-20db022a41d7.htm), [LineElm.GetObj](https://docs.csiamerica.com/help-files/etabs-api-2016/html/2e2f1431-3c90-9c08-f470-b8d90c5f5ce4.htm). ## Generated analytical connectivity comparison

The direct gravity caller now compares current native analytical mesh bytes with the exact assembly-data SHA recorded by the solved OpenSees result, using the original matching source EDB context. Spatial hashing searches adjacent coordinate bins with a 1e-6 m Euclidean tolerance; only mutually unique point matches are used. Structural elements must match source parent, element family and cyclic boundary connectivity (reverse area cycles separately reported). Per-parent counts, unmatched elements/points and ambiguous locations are preserved. A point outside element connectivity is not automatically merged or called a foundation. Different mesh refinement is a diagnostic difference, not an automatic physical rejection. Outputs `ETABS_OpenSees_Analytical_Mesh_Comparison.json` in the existing native quantity folder, included in the review ZIP. No constraint coefficients, stiffness or numerical forces are altered; internal edge MPC equivalence remains unverified. Synthetic tests check cyclic reorder, reversal, crossing ordering, coincident points and source crosswalk conflicts. Original native EDB/current solver result unavailable in this session.
