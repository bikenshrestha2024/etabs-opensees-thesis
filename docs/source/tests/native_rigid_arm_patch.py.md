# Native rigid-arm shear-flexible frame component qualification

[CSI Analysis Reference Manual, Frame Elements, End Offsets](https://docs.csiamerica.com/manuals/etabs/Analysis%20Reference.pdf): rigid end zones alter bending/shear flexibility while axial and torsional flexibility use full length. [OpenSees rigidLink](https://opensees.github.io/OpenSeesDocumentation/user/manual/model/mp_constraint/rigidLink.html) uses small-rotation rigid-arm kinematics. [ElasticTimoshenkoBeam](https://opensees.berkeley.edu/wiki/index.php/Elastic_Timoshenko_Beam_Column_Element) uses independent shear areas. Use explicit master/face slave nodes with rigidLink beam, not an unqualified -jntOffset combination. In a synthetic member of length L and clear length l, scale only A,J by l/L; bending and shear retain source section values. Compare six tip actions with independent compliance formulas. Preserve raw support reaction and expected resultant (MP force recovery is separate). A compression probe exercises native geometric nonlinear response; it is not a quantitative P-Delta equivalence acceptance. This test does not modify production frame topology, loads, mass, supports or release existing combined-offset guard. Run `python -m tests.native_rigid_arm_patch native_rigid_arm_results` with OpenSees Tcl available. No private building data included.

## Native evidence follow-up

Initial native CI run [45939728975](https://github.com/bikenshrestha2024/etabs-opensees-thesis/actions/runs/45939728975) passed 12 displacement/compliance checks (max relative residual 1.5535168e-15) and the compression probe (lateral displacement ratio 1.0323900). Raw retained support reactions did not recover transferred MPC force; the new test additionally records slave reactions and independent element-end forces, translated to the physical support origin. It compares each separately with the first-order analytical resultant; never add a member cut to the nodal recovery. This is isolated component evidence, not the actual building's 44 native edge constraints or 32 supports.

## Force-based original-node alternative

The same test now exercises the actual elastic assembly registration helper through a Tcl command adapter: elastic section with shear factors, forceBeamColumn with three-point Lobatto, and PDelta -jntOffset at the original nodes. Unlike explicit rigidLink face nodes, this avoids chained diaphragm constraints. Twelve end-action compliance, support reaction and element-cut checks plus a compression sensitivity probe are run separately. This is a generic synthetic component, not the full ETABS building. Source mechanics and formulas are in [elastic conversion settings](../components/model/elastic_conversion_settings.py.md).

## Mixed frame/shell discrete interface benchmark

The existing native workflow now also solves a generic two-column and one-shell four-joint specimen under mixed six-component nodal loads. It reads native shell and frame global end-force vectors and support reactions, and runs the same six-DOF interface recovery helper used by the gravity GUI. First-order lower and upper free-body residuals must both be below 1e-7 in the relevant component units. No project model or private data is used. The test does not prove the actual building's foundation or ETABS cut equivalence.
