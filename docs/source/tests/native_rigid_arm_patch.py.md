# Native rigid-arm shear-flexible frame component qualification

[CSI Analysis Reference Manual, Frame Elements, End Offsets](https://docs.csiamerica.com/manuals/etabs/Analysis%20Reference.pdf): rigid end zones alter bending/shear flexibility while axial and torsional flexibility use full length. [OpenSees rigidLink](https://opensees.github.io/OpenSeesDocumentation/user/manual/model/mp_constraint/rigidLink.html) uses small-rotation rigid-arm kinematics. [ElasticTimoshenkoBeam](https://opensees.berkeley.edu/wiki/index.php/Elastic_Timoshenko_Beam_Column_Element) uses independent shear areas. Use explicit master/face slave nodes with rigidLink beam, not an unqualified -jntOffset combination. In a synthetic member of length L and clear length l, scale only A,J by l/L; bending and shear retain source section values. Compare six tip actions with independent compliance formulas. Preserve raw support reaction and expected resultant (MP force recovery is separate). A compression probe exercises native geometric nonlinear response; it is not a quantitative P-Delta equivalence acceptance. This test does not modify production frame topology, loads, mass, supports or release existing combined-offset guard. Run `python -m tests.native_rigid_arm_patch native_rigid_arm_results` with OpenSees Tcl available. No private building data included.
