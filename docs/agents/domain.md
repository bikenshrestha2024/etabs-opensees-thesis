# Domain documentation

The thesis repository uses a single domain context. The project vocabulary lives in the root `GLOSSARY.md` when present. Repository-wide architecture decision records (ADRs) live in `docs/adr/` when present.

Before naming a domain concept in an issue, design proposal, or test, consult the glossary and use its established terms. If a term is missing or ambiguous, raise it when doing domain modeling. Read ADRs relevant to the proposed change and identify any conflicting decision by name or number.
