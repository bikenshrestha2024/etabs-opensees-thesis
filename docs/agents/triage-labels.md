# Triage labels

When an engineering skill names a triage role, apply the corresponding GitHub issue label.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Awaiting initial review |
| `needs-info` | `needs-info` | Awaiting clarification or evidence |
| `ready-for-agent` | `ready-for-agent` | Specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Ready for a person to implement |
| `wontfix` | `wontfix` | Reviewed and declined |
