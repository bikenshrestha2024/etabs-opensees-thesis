# NBC 105:2025 clause 1 compliance matrix (printed pp. 1-9)

Date 2026-11-21. Reference module: [`components/nbc105/clause_01_scope_definitions.py`](../../components/nbc105/clause_01_scope_definitions.py) ([guide](../source/components/nbc105/clause_01_scope_definitions.py.md)). Clause text was read from the page images of the user-supplied PDF: printed page N = PDF page N+21 for printed pp. 1-9 (PDF 22-30); the number printed at the foot of every page was checked (1, 2, ..., 9, no deviation). Definitions are paraphrased, not quoted; notation meanings are the printed wording.

Status values: `IMPLEMENTED_AND_TESTED` (code or data and a unit test exist, checked against the printed page); `DEFINITION_ONLY` (prose definition or statement with nothing machine-checkable; recorded for completeness, not coded).

**Limits.** This matrix records software conformance of the clause 1 data and thresholds only. It is not design acceptance of any building, not an ETABS or OpenSees run, and a unit-test pass is not engineering acceptance. Native ETABS/OpenSees runs are PENDING.

Tests: `T1` = `tests/test_nbc105_clause01.py`, `TP` = `tests/test_nbc105_clause01_parity.py`.

**Row count:** 118 rows = 37 DEFINITION_ONLY, 81 IMPLEMENTED_AND_TESTED.

Notation unit column: the printed list has no units column. Only `g` (m/s^2, printed value 9.81) and `H` (m) print a unit. "derived from 1.5" means derived by this project from the SI statement of 1.5 (kg, m, s, Pa, N), not printed. "not stated" means the symbol is a load or action whose unit (N or Pa) cannot be fixed from the printed text.
