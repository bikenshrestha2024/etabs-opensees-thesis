# 01 — Governing seismic code and supplementary inputs

**Q. Which code governs?** NBC 105:2025 governs seismic methods, spectra, source seismic weight, load combinations, gravity as cross-referenced by TH clauses, ESM, MRSM, linear and nonlinear TH, drift and design acceptance.

**Q. What is mandatory from IS 16700?** Under the researcher's declared thesis design basis: **initial signed EQ P-Delta cases** from IS 16700:2023 §7.2(d), using NBC-derived EL; **conventional RC slab bending stiffness** (0.25 Ig ULS, 0.35 Ig SLS) from IS Table 5, not the NBC beam/column/wall factors. Other IS comparisons are supplementary, not code substitution. The 2025 amendment to IS 16700 requires source-specific reconciliation.

**When/why:** Before modifying any load generator, seismic mass, modal or transient analysis. **Who:** structural reviewer assigns source status; developer verifies exact implementation. **Evidence:** source edition, clause, target variable, source inputs, ULS/SLS and test.
