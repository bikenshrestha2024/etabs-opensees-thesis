# Cooperative edit provenance — not authorship proof
Each substantive actual edit may append `engineering/agent_edits/YYYY-MM-DD/task-slug.json`: tool/provider, observed model if known, branch, base/head Git SHAs, changed files, task, prior-file search, tests actually executed, deferred Windows/native validations, source hash references and UTC timestamp. Unknown tool/model = UNKNOWN. Commit author, PR title and message trailer do NOT prove which assistant generated code. Never record personal chat, access tokens, hidden reasoning or credentials. User/human and assisted edits must be distinguishable. Editor-provided labels are voluntary; GitHub web changes and other clients may bypass local hooks.
