# Scientific and file provenance
Every run stores: UTC timestamp, source Git commit, active source model EDB hash/path (private path redacted in public outputs), original Excel workbook hash and exact adopted source cells if used, model variant M0–M6, ULS/SLS, solver executable/version, configuration hash, units, signs, analysis case, status/exit code, errors and all generated file hashes.
Use one run folder with manifest, input registry, run log, raw results, comparisons, plots, missing_required, missing_optional and upload ZIP. Do not silently reuse stale generated models or silently fill empty Excel/ETABS result tables. Verified matching EDB paths are not proof of matching model contents; verify actual available identities. Keep copyrighted standards, full papers and user files private unless redistribution is authorized. Link DOI/official standards/manufacturer/manual with edition, clause and access date; label verified versus proposed standards separately.
